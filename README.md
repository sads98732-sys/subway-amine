Subway Surfers Clone — "Subway Dash"

A playable 3D endless-runner game for the browser, built in the style of Subway Surfers (SYBO/Kiloo). Run down the tracks, dodge trains and barriers, grab coins and power-ups, and outrun the Inspector.

Built with Muse Spark 1.3 — all art and code are original and generated procedurally at runtime. No assets from the original game are used. Fan-made project, not affiliated with SYBO Games or Kiloo.
